Політика конфіденційності

Ця Політика пояснює, які дані обробляються під час використання VNUMERO, для чого вони використовуються та які права має Користувач.

1. Які дані ми можемо отримувати

Ім’я; дата народження; Telegram user ID та username, якщо доступний; e-mail та/або номер телефону, якщо Користувач їх надає; інформація, добровільно введена в боті або формах сайту; відповіді для персоналізації; інформація про замовлення, платежі та статус доступу; технічні дані, необхідні для роботи, безпеки й діагностики сервісу.

VNUMERO не потребує введення повних реквізитів банківської картки на своєму сервері. Платіжні реквізити обробляються платіжним провайдером.

2. Для чого використовуються дані

Для нумерологічних розрахунків, створення персоналізованих прогнозів і розборів, надання платного доступу, виконання замовлень, комунікації, доставки передбачених сервісом повідомлень, підтримки, безпеки, запобігання зловживанням та виконання законодавчих обов’язків.

3. Підстави обробки

Обробка здійснюється в обсязі, необхідному для надання запитаної послуги, виконання договору, виконання законодавчих обов’язків та, коли це необхідно, на підставі згоди Користувача.

4. Сторонні сервіси

Для роботи VNUMERO можуть використовуватися Telegram, платіжні провайдери, постачальники серверної інфраструктури та баз даних, постачальники технологій штучного інтелекту, а також системи технічного моніторингу. Окремі дані можуть передаватися таким постачальникам лише в обсязі, необхідному для відповідної функції.

5. Штучний інтелект

Окремі персоналізовані матеріали можуть створюватися або опрацьовуватися із застосуванням технологій штучного інтелекту. Для формування відповіді можуть передаватися дані, необхідні для конкретного запиту: ім’я, результати нумерологічних розрахунків, обраний життєвий фокус і наданий Користувачем контекст.

Не слід надсилати через сервіс паролі, банківські реквізити або інші конфіденційні дані, які не потрібні для отримання послуги.

6. Зберігання та захист

Застосовуються організаційні та технічні заходи для захисту даних. Дані зберігаються протягом строку, необхідного для роботи сервісу, виконання договірних і законодавчих обов’язків, вирішення спорів та забезпечення безпеки. Окремі технічні журнали можуть зберігатися протягом обмеженого строку.

7. Платіжні дані

VNUMERO може отримувати статус платежу, суму, номер замовлення та інші технічні відомості, необхідні для підтвердження оплати. Повні реквізити банківської картки VNUMERO не зберігає.

8. Повідомлення в Telegram

Користувач може отримувати персоналізовані прогнози, повідомлення про стан доступу та сервісні повідомлення, які є частиною функціональності VNUMERO. Користувач може припинити взаємодію з ботом або звернутися до підтримки щодо припинення повідомлень, якщо це технічно та юридично можливо.

9. Права Користувача

Користувач може звернутися щодо доступу до інформації про обробку своїх даних, їх уточнення, виправлення або видалення у випадках, передбачених законодавством, а також відкликання згоди, коли обробка здійснюється на її підставі.

10. Дані інших осіб

Користувач не повинен передавати персональні дані іншої особи без належних підстав. Якщо вони необхідні для певної послуги, Користувач підтверджує наявність законних підстав для їх надання.

11. Зміни Політики

Політика може оновлюватися. Актуальна редакція публікується на офіційному вебсайті VNUMERO.
